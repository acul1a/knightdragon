# Дорожная карта (WebXR-версия)

Движок: **Three.js + WebXR**, запуск в браузере Meta Quest, публикация через **GitHub Pages**. Это заменяет Unity-вариант из первого плана: сборка APK не нужна, игру открывают по ссылке.
