# Рыцарь: Пленница дракона

VR-приключение от первого лица для **Meta Quest 2**, которое открывается прямо в браузере по ссылке (WebXR + Three.js). Игрок держит меч и щит, сражается с чудовищами и спасает принцессу.

**Сейчас готово:** все 8 уровней — от разрушенной деревни до замка дракона. На каждом уровне сначала враги, потом босс, затем награда, которая усиливает героя. Прогресс сохраняется в браузере.

| № | Уровень | Враги и босс | Награда |
|---|---|---|---|
| 1 | Окраина королевства | гоблины, главарь | щит |
| 2 | Заколдованный лес | пауки, паучья матка | амулет здоровья (+1 сердце) |
| 3 | Заброшенные шахты | скелеты, каменный голем | боевой молот (урон +25%) |
| 4 | Затопленные руины | болотники, хранитель руин | ледяной клинок (враги медленнее) |
| 5 | Крепость тёмного ордена | воины, чёрный рыцарь (блокирует) | усиленный щит |
| 6 | Огненное ущелье | огненные создания, страж (огненное дыхание) | амулет защиты от огня |
| 7 | Подступы к замку | элитные стражи, командир | зачарование меча (больше урона по боссам) |
| 8 | Замок дракона | дракон: 3 фазы, огненное дыхание, укрытия | спасение принцессы |

## Как играть

**На Quest 2 (браузер Meta Quest Browser)**
1. Открой ссылку на игру: `https://acul1a.github.io/knightdragon/`
2. Нажми **Enter VR**.
3. Правая рука — меч, левая — щит. Левый стик — ходьба, правый стик — поворот рывками.
4. Враг замахивается (краснеет и поднимает оружие) — подставь щит под удар или отойди. Бей мечом **резкими замахами**: чем быстрее взмах, тем сильнее удар.
5. Огненное дыхание блокируй щитом или прячься за камнями.
6. После победы над боссом подбери награду рукой — следующий уровень начнётся сам.
7. Чтобы проверить любой уровень сразу, добавь к адресу `?level=N`, например `.../knightdragon/?level=8`.

**На компьютере (для быстрой проверки)**
- `WASD` — ходьба, мышь с зажатой кнопкой — обзор
- Левая кнопка мыши — удар, `Shift` или правая кнопка — блок

## Как опубликовать на GitHub Pages

1. Загрузи все файлы из этой папки в корень репозитория `acul1a/knightdragon` (ветка `main`): `index.html`, `main.js`, `README.md`, папку `docs/`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
3. Через 1–2 минуты игра будет доступна по ссылке `https://acul1a.github.io/knightdragon/`.

> WebXR работает только по HTTPS — GitHub Pages это обеспечивает.

## Структура

```
index.html   страница и подсказки по управлению
main.js      вся игра: 8 уровней, враги и боссы, меч и щит, награды, сохранение, управление
docs/ROADMAP.md   дорожная карта на 8 уровней
```

Three.js подключается с CDN (jsDelivr), сборка не нужна: правишь файл → коммитишь → Pages обновляется.
