# Рыцарь: Пленница дракона

VR-приключение от первого лица для **Meta Quest 2**, которое открывается прямо в браузере по ссылке (WebXR + Three.js). Игрок держит меч и щит, сражается с чудовищами и спасает принцессу.

**Сейчас готово:** Уровень 1 «Окраина королевства» — разрушенная деревня, меч, щит, гоблин, эликсир в награду.

## Как играть

**На Quest 2 (браузер Meta Quest Browser)**
1. Открой ссылку на игру: `https://acul1a.github.io/knightdragon/`
2. Нажми **Enter VR**.
3. Правая рука — меч, левая — щит. Левый стик — ходьба, правый стик — поворот рывками.
4. Гоблин замахивается дубиной (краснеет и поднимает её) — подставь щит под удар или отойди. Бей мечом **резкими замахами**: чем быстрее взмах, тем сильнее удар.
5. После победы подбери эликсир рукой.

**На компьютере (для быстрой проверки)**
- `WASD` — ходьба, мышь с зажатой кнопкой — обзор
- Левая кнопка мыши — удар, `Shift` или правая кнопка — блок

## Как опубликовать на GitHub Pages

1. Загрузи все файлы из этой папки в корень репозитория `acul1a/knightdragon` (ветка `main`): `index.html`, `main.js`, `README.md`, папку `docs/`.
2. В репозитории: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**.
3. Через 1–2 минуты игра будет доступна по ссылке `https://acul1a.github.io/knightdragon/`.

> WebXR работает только по HTTPS — GitHub Pages это обеспечивает.

## Структура

```
index.html   страница и подсказки по управлению
main.js      вся игра: мир, меч и щит, боевая система, ИИ гоблина, управление
docs/ROADMAP.md   дорожная карта на 8 уровней
```

Three.js подключается с CDN (jsDelivr), сборка не нужна: правишь файл → коммитишь → Pages обновляется.
